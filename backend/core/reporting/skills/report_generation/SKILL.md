# Report Generation Skill

How analytical reports are planned and assembled in this system.

## Workflow

1. Build the working context (scope, entities, metrics, conflicts).
2. Write a Report Plan IR and validate its section types.
3. Research each section with deterministic tools first.
4. Compute with the analyst; never arithmetic in prose.
5. Draft structured blocks (paragraph/table/chart), each with claim IDs.
6. Audit numerically, then revise once, then render.

## Section order

Executive summary, sourced analysis sections, verification notes,
sources appendix with receipts.

## Quality rules

- No number without a source ref.
- Charts carry units on axes and a finding in the title.
- The executive summary must reflect the body, not introduce new figures.
