# Validation Skill

What the auditor checks, and how strictly.

## Numerical checks

- Re-derive every calc from its recorded inputs and formula.
- Tolerance: exact match after rounding to the reported decimals.
- Units must match across claim, calc and sources.

## Evidence checks

- Every claim resolves to at least one source with doc + page/sheet.
- Every chart file exists and its row counts match the analysis table.
- Conflicting values on a reported key must appear in verification notes.

## Verdicts

- FAIL: any number that cannot be re-derived, or any claim without a source.
- WARNING: low-confidence sources, partial-year exclusions, unresolved conflicts.
- PASS: everything re-derives and resolves.
